# Aron Henriquez — Professional Portfolio

Personal portfolio website for Aron Henriquez, Senior CRM & Lifecycle Marketing Analyst based in Rio de Janeiro, Brazil.

## Pages

- **`index.html`** — Home / landing page with hero, skills, expertise overview, and blog preview
- **`about.html`** — About me, background, education, and skills sidebar
- **`experience.html`** — Full career history with competencies and tools
- **`blog.html`** — Blog post listing
- **`blog/post-1.html`** — *Why most companies fail at lifecycle marketing*
- **`blog/post-2.html`** — *The anatomy of a great onboarding journey*
- **`blog/post-3.html`** — *A/B testing: doing it right vs doing it fast*

## Tech

Pure HTML, CSS, and vanilla JavaScript — no frameworks, no build step. Just open `index.html` in a browser or deploy the folder to any static hosting.

## Hosting (GitHub Pages)

1. Go to your repo **Settings → Pages**
2. Under **Source**, select **Deploy from a branch**
3. Choose **main** branch and **/ (root)** folder
4. Save — your site will be live at `https://<your-username>.github.io/professional-portfolio/`

## Adding a new blog post

1. Duplicate any existing file in the `blog/` folder (e.g. `post-3.html`)
2. Rename it (e.g. `post-4.html`)
3. Update the title, date, tag, and content inside
4. Add a link to it in `blog.html` and optionally in `index.html`'s blog preview section

## Customization

- **Colors:** all defined as CSS variables at the top of `css/style.css`
- **Fonts:** Google Fonts — DM Serif Display + DM Sans
- **Contact/social links:** search for `linkedin.com/in/aronhenriquez-crm-lifecycle` to update links
